# Interfaz de Usuario

## 1. Principios usados
- Navegacion por rol.
- Paneles claros por contexto (estudiante, conductor, admin).
- Responsive en desktop y movil.

## 2. Vistas principales
- Login
- Dashboard
- Mapa en tiempo real
- Rutas
- Buses
- Notificaciones
- Perfil
- Conductor: Mi recorrido
- Admin: panel y modulos de gestion

## 3. Mejoras UX incorporadas
- Panel conductor colapsable en movil.
- Selector de parada en mapa + busqueda de direccion.
- Modal de paradas en dos columnas en desktop.
- Notificaciones por tipo (info, retraso, cambio de ruta).

## 4. Pruebas de usabilidad sugeridas
- Tiempo para registrar una parada.
- Tiempo para asignar conductor y ruta.
- Lectura de notificacion en menos de 3 toques en movil.
